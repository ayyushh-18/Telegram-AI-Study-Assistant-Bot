# AI Study Assistant Bot 🤖

Advanced AI-powered Telegram Study Assistant built using Python and Groq API.

## Features

- AI Question Answering
- Notes Summarizer
- MCQ Quiz Generator
- Flashcards Generator
- Exam Preparation
- PDF Summarizer
- Learning Roadmaps
- Practice Tests
- Chat History

## Tech Stack

- Python
- Telegram Bot API
- Groq API
- SQLite
- PyMuPDF

## Commands

- /ask
- /summarize
- /quiz
- /flashcards
- /roadmap
- /practice
- /exam
- /history

## Setup

```bash
pip install -r requirements.txt
python main.py
